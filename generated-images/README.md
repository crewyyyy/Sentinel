- `sentinel-avatar-1024.png`: 1024 × 1024, аватарка без текста, с полями под круглую обрезку.
- `sentinel-message-pipeline-readme.png`: 1536 × 900, схема проверки сообщений для README. Создана через MCP imagegen; нижние примечания генератора убраны кадрированием. Запрошено качество `high`, провайдер вернул `medium`.

Оригиналы MCP imagegen сохранены отдельно: `sentinel-banner.png` (1536 × 1024) и `sentinel-avatar.png` (1254 × 1254). Промпты: `banner-prompt.md`, `avatar-prompt.md`, `message-pipeline-prompt.md`. Визуальное направление: `visual-direction.md`.
