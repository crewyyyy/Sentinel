# Смена модели в Telegram

В закрытом админ-чате или разрешённом ЛС:

1. `/model` или `/models` — текущая модель и каталог настроенного endpoint.
2. Кнопки показывают по шесть моделей на страницу. `✓` отмечает текущую; `← Назад`/`Вперёд →` листают страницы.
3. `/model luna` — поиск подстроки в ID модели; подходит также `/model clodex/` для соответствующего маршрута провайдера.
4. Выберите модель. На отдельном экране проверьте полный ID и нажмите **«Применить»** либо **«Назад к списку»**.

## Что меняется

- Общая модель для всех управляемых чатов. Нужны allowlisted numeric user ID и актуальные права администратора **во всех** этих чатах.
- Выбор сохраняется в `runtime_ai_model`. После рестарта он приоритетнее YAML/`AI_MODEL`; env используется только до первого runtime-выбора. Для возврата к deployment-модели выберите тот же ID в каталоге.
- Новые попытки, включая повторы pending jobs, читают модель из БД при claim. Уже начатый HTTP-запрос продолжает работу на своей модели. Готовые reviews не оплачиваются повторно только из-за смены настройки.
- На попытке сохраняются `model` и `prompt_version`; на успешном review — выбранный маршрут. Общий provider/config не изменяется конкурентно в памяти.
- Явная смена сбрасывает provider circuit pause и ожидание ранее ошибочных pending jobs. Optional budget продолжает действовать, mandatory jobs не удаляются.
- Изменения пишутся в `model_change_events` с actor, old/new и idempotency key; retention 90 дней.

## Защита кнопок

Панель принадлежит своему автору, привязана к chat ID и реально отправленному message ID, живёт 30 минут. Callback содержит только ID панели, её ревизию и индекс — не ключ и не длинное имя модели. На каждом действии повторно проверяются права. Старые кнопки и подтверждение, подготовленное до чужой смены модели, не перезаписывают новое решение. Перед доставкой меню повторно проверяются приватность destination и права автора во всех чатах.

При недоступном `/models` или ошибке формата каталог не подменяется вымышленным списком; текущая настройка сохраняется. Новый запрос каталога ограничен по времени/размеру; страницы используют сохранённый snapshot, не вызывают API заново.

## Совместимость и деньги

Каталог `/models` может включать embeddings, изображения и модели без нужного JSON/chat-completions режима. Наличие в каталоге **не доказывает совместимость**, subscription или нулевую стоимость. Смена не выполняет скрытый платный probe и не переключается на другую модель при ошибке. Неподдерживаемая модель оставит jobs pending/retrying; выберите рабочую.

Цены YAML относятся только к исходному `AI_MODEL`. После выбора другого ID usage сохраняется при наличии, а денежная оценка считается неизвестной, не пересчитывается по чужому тарифу. Название маршрута само по себе не гарантирует способ биллинга — проверьте тариф у своего провайдера.

Prompt `review_v2` сохраняет lowercase `json` и в системной инструкции, и в user envelope (`format=json`), поскольку некоторые subscription-шлюзы проверяют JSON-mode только по user input. Новые попытки используют актуальную версию; существующие завершённые reviews неизменны. В автоматических тестах только fake API, без настоящих ключей.
