# Смена модели AI

Откройте `/model` или `/models`, выберите модель и нажмите «Применить модель». Поиск: `/model luna` или `/model clodex/`. Каталог показывает по шесть моделей на странице.

Выбор общий для всех чатов, поэтому нужны allowlist и права администратора во всех управляемых группах. Настройка сохраняется в PostgreSQL и имеет приоритет над `AI_MODEL` после restart. Новые попытки, включая повторы, используют выбранную модель; выполняющиеся запросы продолжаются на прежней.

## Ошибки каталога

| Ответ | Что проверить |
|---|---|
| 401 | `AI_API_KEY` и endpoint провайдера |
| 403 | Доступ ключа к каталогу |
| 429 | Лимит запросов провайдера |
| Timeout / 5xx | Доступность endpoint; повторите `/model` позже |

Каталог читается из `<AI_BASE_URL>/models`. Ошибка не меняет текущую модель. Ключ задаётся на сервере, не через Telegram. После изменения env пересоздайте контейнер по [инструкции обновления](operations.md#обновление-и-rollback).

## Совместимость и стоимость

Для проверки сообщений нужны Chat Completions и JSON-ответ. Каталог может содержать модели для изображений и embeddings; выбирайте подходящую у своего провайдера. При несовместимости задания остаются в очереди до исправления настройки.

Цены YAML относятся к исходному `AI_MODEL`. Для другой модели сохраняются usage, а денежная оценка остаётся неизвестной. Тариф проверяйте у провайдера.

Панель действует 30 минут. Смена требует отдельного подтверждения, проверяет текущие права и записывается в аудит на 90 дней. Нажатия страниц используют сохранённый каталог без новых API-запросов.
