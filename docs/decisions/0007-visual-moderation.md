# 0007: NSFW-проверка медиа отдельно от текстового AI

2026-11-13.

Провайдер fal-ai/imageutils/nsfw принимает изображения. Для GIF и видеостикеров используем до трёх кадров, для TGS только Telegram-превью. Не обещаем анализ всей анимации. Неуспешная проверка сохраняется как unavailable.

Общая Postgres-очередь дедуплицирует Telegram file_unique_id/custom emoji ID. SHA-256 кэш PNG-кадров исключает дополнительные вызовы для одинаковых изображений под разными ID. Одна рабочая goroutine обрабатывает медиа; leases и fencing восстанавливают работу после сбоя. Кэш долговечный, временные файлы не архивируются.

Fal получает PNG data URI, не Telegram URL с токеном. Новая зависимость runtime: ffmpeg. Декодер запускается без shell, с явным форматом, ограничениями памяти входа/выхода, пикселей, времени и протоколов. Внешние URL из контейнеров медиа не открываются.

В личке сканер доступен операторам из allowed_admin_ids, чтобы посторонние не расходовали оплаченные кредиты. Подписи и личный текст для сканера не сохраняются. Ответ идёт через outbox реплаем; оформление отражает результат. В группах сохраняются consent и ignore-admin фильтры, результат дополняет обычный кейс.

Визуальные проверки optional: отдельный дневной лимит и TTL, не влияющие на четыре обязательных текстовых триггера. При исчерпании бюджета задача pending, в личке одно уведомление. После восьми ошибок unavailable; для повторных медиа такой результат действует 15 минут. Сетевые повторы могут повторно тарифицироваться.

Схема, настройки, политика внешней обработки и откат описаны в ../media-moderation.md. Исторические вердикты сохраняются, а не пересчитываются при изменении порогов.
